# IB Intermodal Prototype 1 – Intermodal Trip Records (Vertt × SBB)

Builds three mock intermodal trips (Vertt ride-hailing + SBB train via the OJP 2.0 API) and renders them on a static web page.
Full specification: [docs/PROTOTYPE_1_BRIEF.md](docs/PROTOTYPE_1_BRIEF.md).

> Status: work in progress (repo skeleton).

## Setup

```bash
python -m venv .venv
.venv\Scripts\activate          # Windows
pip install -r requirements.txt
copy .env.example .env          # then put your OJP API key into .env
```

Put `station_rides_mock_trips.xlsx` into `data/raw/` (gitignored, contains personal data).
